# 🚀 Portfolio Professionnel - Maxime HANS

> Portfolio développé dans le cadre de l'épreuve U5 du **BTS SIO (Services Informatiques aux Organisations) option SISR**. 
> Ce site sert de carte de visite professionnelle pour mes recherches d'alternance, de stages et d'emplois, tout en présentant mes compétences, mes projets et ma veille technologique.

---

## 🎯 Aperçu du Projet

Ce projet a été conçu selon une approche **One-Page**, épurée, moderne et orientée utilisateur (recruteurs, formateurs, étudiants). 

### ✨ Fonctionnalités & Points Forts
* **Design & Identité Visuelle :** Palette de couleurs soignée (bleu océan/cyan), typographie *Doppio One* et intégration d'un logo typographique minimaliste (`MH.`).
* **Expérience utilisateur (UI/UX) :** 
  * Navigation fluide (*Smooth Scroll*) à travers les sections.
  * Bulles d'informations interactives pour afficher ou masquer les détails techniques sans surcharger la page.
  * Formulaire de contact avec ciblage dynamique (Entreprise, Étudiant, Professeur).
  * Bouton d'accès direct vers mon profil LinkedIn intégré avec icône FontAwesome.
* **Mode Sombre Automatique :** Gestion native du thème sombre via CSS en fonction des préférences système du visiteur.
* **Page 404 Créative :** Page "Introuvable" thématique dotée d'animations graphiques purement en CSS (animation de câbles électriques débranchés, étincelles multicolores).
* **Responsive Design :** S'adapte de manière fluide à tous les types d'écrans (ordinateurs, tablettes, smartphones).

---

## 🛠️ Stack Technique

Le projet a été développé en respectant strictement les contraintes académiques (sans framework, sans CMS, sans bibliothèque externe lourde) :
* **HTML5 Sémantique** (structure propre, balises sémantiques `<header>`, `<nav>`, `<section>`).
* **CSS3 Moderne** (Variables CSS/Custom Properties, Flexbox, CSS Grid, Media Queries, animations `@keyframes`).
* **FontAwesome** (pour les icônes vectorielles).
